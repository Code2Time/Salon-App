# تصمیم‌ها و ابهام‌ها

این فایل تفاوت «نیازمندی»، «پیشنهاد» و «تصمیم پذیرفته‌شده» را حفظ می‌کند. تصمیم جدید با تاریخ، وضعیت، دلیل و اثر بر Database/API/UI ثبت شود؛ تصمیم جایگزین‌شده حذف نشود و به جایگزین ارجاع بدهد.

## الزامات تثبیت‌شده در BasePrompt

- Laravel API و React + TypeScript + Vite + MUI.
- رابط فارسی و RTL؛ Theme مرکزی و معماری ماژولار.
- توسعهٔ مرحله‌ای و آمادگی جداسازی داده‌های چند سالن از ابتدا.
- مدت خدمت، برنامهٔ کارکنان و قوانین قابل تنظیم، مبنای رزرو هستند.

## تصمیم پذیرفته‌شده — ترتیب Foundation

- تاریخ: 2026-10-07؛ مرجع: درخواست کاربر برای اختصاص تسک اول به Layout پنل و اپ مشتری.
- تسک 01 فقط Layoutها، Theme، RTL و مسیریابی را پوشش می‌دهد.
- API، احراز هویت و زمینهٔ سالن به تسک 01b منتقل شدند و پیش‌نیاز فاز 02 باقی می‌مانند.
- در تسک Layout، Database و API تغییر دامنه‌ای ندارند؛ پیش‌نمایش‌ها دادهٔ خصوصی ندارند.

## تصمیم پذیرفته‌شده — Layoutهای اولیه

- تاریخ: 2026-10-07؛ مرجع: اجرای تسک 01 به درخواست کاربر.
- نام «آرا» و اطلاعات سالن صرفاً نمایشی‌اند؛ رابط دادهٔ تجاری یا حساب واردشدهٔ ساختگی ندارد.
- دو Layout مستقل در `/panel` و `/app`، با React Router و مسیرهای تو‌در‌تو پیاده شده‌اند. `/` انتخاب پیش‌نمایش است.
- Theme مشترک Ivory/Mauve، فونت محلی Vazirmatn با مجوز OFL و آیکن‌های Lucide استفاده شده‌اند. منبع مجوز فونت در `public/licenses/vazirmatn.txt` موجود است.
- RTL با جهت سند، Theme و Emotion cache انجام شده؛ Drawer با anchor منطقی `left` در Theme RTL از سمت راست باز می‌شود.
- صفحات داخلی جای‌نگهدارند؛ API و Database تغییری نکرده‌اند. Route پوسته مسیرهای API و منابع static را کنار می‌گذارد.
- راهنمای اجرا: `Ai/LocalDevelopment.md`. زیرساخت احراز هویت و Tenant Context همچنان متعلق به تسک 01b است.
