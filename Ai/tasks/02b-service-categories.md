# تسک 02b — مدیریت دسته‌بندی خدمات

## هدف

مدیریت دسته‌بندی‌های پویا و سالن‌محور برای آماده‌سازی کاتالوگ خدمات و جریان رزرو. هر خدمت می‌تواند هم‌زمان در چند دسته‌بندی قرار بگیرد؛ برای مثال «میکاپ عروس» می‌تواند عضو دسته‌های «عروس» و «میکاپ» باشد.

## تصمیم‌ها

- رابطه خدمات و دسته‌بندی‌ها چندبه‌چند و از طریق `service_category_service` است.
- دسته‌بندی شامل نام، توضیح nullable، تصویر nullable، وضعیت ویژه، وضعیت فعال و ترتیب نمایش است.
- نام دسته‌بندی میان رکوردهای فعال همان سالن یکتا است و داده‌ها همواره با Salon Context محدود می‌شوند.
- دسته‌بندی و خدمت قابلیت Soft Delete دارند تا سوابق آینده آسیب نبینند.
- پیش از حذف، API اثر حذف و نام خدمات مرتبط را برمی‌گرداند و UI آن‌ها را در Dialog نمایش می‌دهد.
- حذف دسته‌بندی ارتباط آن را با همه خدمات قطع می‌کند. خدمت دارای دسته دیگر باقی می‌ماند و فقط خدمت بدون هیچ دسته‌بندی دیگری Soft Delete می‌شود.
- مجوز `service_categories` فقط مشاهده و مجوز `manage_service_categories` ایجاد، ویرایش و حذف را می‌دهد. مجوز مدیریت به‌صورت ضمنی مجوز مشاهده را نیز فعال می‌کند.
- مدیر سالن و Super Admin دسترسی کامل دارند؛ کارکنان بر اساس دو مجوز بالا محدود می‌شوند.

## محدوده پیاده‌سازی‌شده

- جدول‌های `service_categories`، `services` و pivot رابطه چندبه‌چند؛ جدول پایه خدمات برای تثبیت رابطه ایجاد شده ولی CRUD خدمات به تسک بعدی واگذار شده است.
- مدل‌ها و روابط Salon، ServiceCategory و Service.
- API فهرست صفحه‌بندی‌شده، جستجو، فیلتر وضعیت/ویژه، مشاهده، ایجاد، ویرایش، پیش‌نمایش اثر حذف و حذف امن.
- پارامتر فیلتر ویژه در Frontend به‌صورت صریح با `1` و `0` ارسال می‌شود تا هر دو حالت «ویژه» و «عادی» با اعتبارسنجی boolean لاراول سازگار باشند.
- آپلود و جایگزینی JPG/PNG/WebP تا ۲ مگابایت.
- UI فارسی و Responsive در `/panel/service-categories` با Loading، Empty، Error، فیلتر، فرم و Dialog حذف.
- Dialog جزئیات دسته‌بندی وضعیت‌ها و فهرست خدمات مرتبط را همراه مدت و وضعیت خدمت نمایش می‌دهد.
- جداسازی دسترسی مشاهده و مدیریت در فرم مجوز کارکنان و Backend.

## خارج از محدوده

- CRUD خدمات، تخصیص دسته‌ها به خدمت در UI و اتصال کارکنان ارائه‌دهنده.
- نمایش عمومی دسته‌بندی‌ها در اپ مشتری.
- بازیابی رکوردهای Soft Delete شده.
