# 06f — نصب اپ مشتری روی گوشی

مرجع: درخواست مستقیم کاربر برای شروع نصب اپ مشتری. پیش‌نیاز: اپ React، احراز هویت و هویت عمومی سالن. وضعیت و نتایج اجرا در `../ProjectStatus.md` ثبت می‌شوند.

## دامنه

- PWA با manifest فارسی و RTL، نام/آیکن سالن و اجرای مستقل از مرورگر.
- صفحه عمومی نصب، ورودی از خانه/پاورقی، تشخیص حالت مستقل، دکمه نصب فقط در صورت پشتیبانی مرورگر و راهنمای Android/iOS.
- worker نسخه‌دار در Build، fallback قطع اتصال و به‌روزرسانی با اقدام کاربر.
- عدم Cache اطلاعات خصوصی و عدم ثبت رزرو یا سفارش آفلاین.
- توضیح محدودیت HTTP شبکه و نیاز HTTPS برای نصب واقعی گوشی؛ بدون راه‌اندازی خودکار Tunnel یا انتشار عمومی.

## معیار پذیرش

- Manifest عمومی با آیکن معتبر و metadata نصب در HTML؛ تست fallback نبود لوگو/سالن.
- worker فعال روی Build در محیط امن و صفحه قطع اتصال هنگام نبود شبکه.
- Cache محدود به فایل ثابت و صفحه عمومی قطع اتصال؛ API و احراز هویت Cache نشوند.
- نسخه جدید بدون Reload خودکار وسط کار اعلام شود و با اقدام کاربر فعال شود.
- صفحه نصب در موبایل/دسکتاپ، راهنمای iOS و HTTP شبکه بررسی شوند؛ رویداد شبیه‌سازی‌شده از نصب واقعی گوشی متمایز گزارش شود.

APK، فروشگاه اپ، Push Notification، سرور عمومی و عملیات آفلاین خارج از دامنه‌اند.
