# تسک 02d — داشبورد عملیاتی سالن

## هدف

جایگزینی پیش‌نمایش ثابت صفحه اصلی پنل با داشبورد Responsive و متکی به داده واقعی همان سالن.

## تصمیم‌ها

- شاخص‌های مالی تا پیاده‌سازی فاز 04 نمایش داده نمی‌شوند تا عدد ناقص یا ساختگی ارائه نشود.
- «امروز» با منطقه زمانی تنظیم‌شده سالن و در نبود آن با `Asia/Tehran` محاسبه می‌شود.
- نوبت‌های پیش رو فقط وضعیت‌های `pending` و `confirmed` را شامل می‌شوند و به پنج مورد نزدیک محدودند.
- دسترسی API برای Owner و Super Admin آزاد و برای Employee وابسته به مجوز `dashboard` است.

## محدوده پیاده‌سازی‌شده

- API سالن‌محور `GET /api/panel/dashboard`.
- تعداد نوبت‌های امروز و تفکیک تأییدشده، انجام‌شده و لغوشده.
- تعداد مشتریان، کارکنان و سرویس‌های فعال.
- پنج نوبت نزدیک با مشتری، سرویس‌ها و متخصصان.
- برنامه حضور امروز همه کارکنان فعال با وضعیت حاضر، غایب یا ثبت‌نشده.
- UI فارسی، RTL و Responsive با Loading، Error، Empty State و میانبرهای متناسب با دسترسی.
- تست Feature برای آمار واقعی، جداسازی سالن، مجوز کارمند و مهمان.

## خارج از محدوده

- درآمد، پرداخت، نمودار مالی و گزارش خدمات محبوب تا تکمیل داده‌های فاز 04.
- تنظیمات عمومی و اطلاعات تکمیلی سالن.
